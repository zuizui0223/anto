# ANTO v26 — 実際のPetunieae 59種で、どの花器官発現情報が色素量を予測するか

**2026-10-28｜今回の新しい実データ解析。** Wheeler, Dunbar-Wallis, Schutz & Smith (2023), *Proceedings of the Royal Society B*, DOI [10.1098/rspb.2023.0275](https://doi.org/10.1098/rspb.2023.0275), 著者の公開[OSF zg9cu](https://osf.io/zg9cu/)を用いた、**原著提供の処理済み花芽RNA発現とHPLC色素量を新しい固定モデルで交差検証した二次解析**。原著RNA生リード・HPLCクロマトグラムからの独立再定量、遺伝子機能編集、自然での祖先色再進化の追跡ではない。

## 問いと今回の結果

ANTO v25で検討したIochrominaeの2019年原著では、原著の掲載AICにおいてCHI発現モデルが**種間のアントシアニン量とフラボノール量**の最良の回帰候補だった。しかし、それは**同じ系統群の原著適合度**であり、別の系統・別のモデルによる外挿性能を示していない。

今回、Petunieae（同じナス科の**異なるtribe**）の**実際の種別データ**を用い、次の限定的だが独立に計算可能な問いを評価した。

> 現在の花芽RNAのどの組合せが、まだモデルに使っていない**種の現在の花の化学的色素量**をより正確に予測するか？

**結果：** CHI単独はアントシアニン量で種単位ホールドアウトの訓練平均を改善しなかった。一方、分岐経路のF3′H・F3′5′H・FLSの3発現量、または他の3遺伝子を加えた組合せは、アントシアニン量とフラボノール量の両方の予測誤差を低下させた。**これは現在の色素量の関連予測であって、祖先形質を未来に再発現できる機能の実測ではない。**

## 取得・完全性検証した原著処理済みデータ

公式OSF v2メタデータからファイルID、サイズ、MD5・SHA-256を確認し、GitHub Actions上で原ファイル**本体**を取得。各ファイルについて**登録されたバイト長とMD5・SHA-256全ての一致**を確認した。元ファイルのバイト列はANTOへ再配布しない。

| 元著者のOSFファイル | サイズ | 役割 |
|---|---:|---|
| phyloCCA/tpm10k-mgg-combined-with-flavs.csv | 26,917 bytes | 種ごとの色素経路RNAとHPLC由来化学量の結合処理済み表 |
| salmon_expression_quantification/target_gene_expression_mean_handle_multiplicity-tpm10k.csv | 30,410 bytes | 独立ファイルとして照合する原著の平均発現表 |
| dataset_summary_statistics/pigment_distributions/combined-antho-flav-mgg-mean-4letter-codes.csv | 7,039 bytes | 独立ファイルとして照合する化学量 |
| phyloCCA/11genestre_dated_pruned.tre | 1,481 bytes | 原著系統樹を元ソースとして保全（**今回の回帰に系統モデルとして組み込んでいない**） |
| stochastic_mapping/phyloPCA-pigment-kmeansclust-IDs.csv | 551 bytes | 原著色素クラスター表の存在・完全性のみ確認（**新しい色分類器には使用していない**） |

3つの処理済みCSVの**原著種コード60件の集合**が一致。9化学量×60種＝**540値**、選んだ8発現項目×60種＝**480値**が、別々の著者提供CSVの間で数値一致した。外群コード**BROW（*Browallia*）**の1行は予測から除外し、**Petunieaeの内群59種**をそれぞれ一度だけテスト対象とした。

注意：これは**同じ種コード**での照合であり、RNAとHPLCが**同じ個体・花器官・発育時点**で両方測定されたと確証するものではない。種ごとの集計値をそれぞれ1つの解析単位として扱い、60行を60の独立した祖先色の再獲得事象として数えない。

元著者のOSF全体の階層・ファイル一覧の完全集計はフォルダ深さ・ファイル名重複の検証ゲートにより**途中不採用**。ここで生物学的解析に使った**5指定ファイルの元バイトの完全性検証は別々に成功**した。未走査ファイルの存在を否定しない。

## 事前に固定した6つのモデルと2つの応答

元CSVの花芽RNA発現は各遺伝子の**log(1+TPM10K)**に変換した。化学量はアントシアニン6化合物（Del、Cyan、Pet、Pel、Peon、Malv）の**合計に対するlog(1+合計)**と、フラボノール3化合物（myr、quer、kaem）の**合計に対するlog(1+合計)**を**別々に**予測する。

比較したモデルは、**①訓練種の平均だけ、②CHI単独、③CHS・CHI・F3H（上流3）、④DFR・ANS（下流2）、⑤F3′H・F3′5′H・FLS（分岐3）、⑥CHI・F3′H・F3′5′H・DFR・ANS・FLS（6遺伝子）**。

推定は切片つき、標準化した説明変数のridge回帰で、**正則化係数λ=10を固定**。標準化平均・分散、切片、係数は全て**テスト種を除いた訓練集合内で推定**した。色素応答列を説明変数に入れない。今回のモデルセットを元論文や全種でハイパーパラメータ最適化した結果と誤認しない。

**目的変数に「目で見た花色」「祖先色が再出現したか」「充実種子・次世代繁殖」は含まない**。平均だけのモデルは「現在の可視花色だけで予測するモデル」ではなく、単に訓練データの平均というゼロ情報基準である。

## 新しい実データによる種単位の留一交差検証

59種のうち1種を全て訓練から外して予測する操作を59回繰り返した。表中は**元HPLC化学量をlog(1+合計)した応答での種別RMSE**で、**小さいほど予測誤差が小さい**。

| モデル | アントシアニン量 RMSE | フラボノール量 RMSE |
|---|---:|---:|
| 訓練種の平均のみ | 0.390797 | 1.377145 |
| CHIのみ | 0.396685 | 1.369020 |
| 上流3遺伝子 | 0.406332 | 1.520243 |
| DFR・ANS | 0.350229 | 1.415927 |
| **分岐3遺伝子** | **0.329612** | **1.186676** |
| 6遺伝子組合せ | **0.326321** | **1.162451** |

同じfold定義の訓練平均モデルと比較したRMSEの低下率では、分岐3遺伝子が**アントシアニン15.66%、フラボノール13.83%**、6遺伝子が**16.50%、15.59%**。CHI単独はアントシアニンで**1.51%悪化**、フラボノールでは**0.59%改善**に過ぎない。ここでの改善は**この著者公開データ・モデル定義・評価法内**の予測成績である。

## もう一つの頑健性点検：種コード先頭2文字のグループ除外

同じ59種を、原著の4文字コードの**先頭2文字が同じもの**で19グループに分け、グループを丸ごと除いて予測した。**この2文字は厳密な分類学上の属・独立祖先クレードとしては検証していない**。系統樹で定義した系統別の外挿試験ではなく、species-LOOより広い**便宜的なコード群ホールドアウト**である。

| モデル | アントシアニン量 RMSE | フラボノール量 RMSE |
|---|---:|---:|
| 訓練種の平均 | 0.417037 | 1.404824 |
| CHIのみ | 0.430272 | 1.413555 |
| 上流3遺伝子 | 0.429291 | 1.602648 |
| DFR・ANS | 0.387550 | 1.537405 |
| **分岐3遺伝子** | **0.354954** | **1.198868** |
| 6遺伝子組合せ | 0.361354 | 1.224097 |

この粗いグループ除外でも分岐3遺伝子は、訓練平均に対し**アントシアニン14.89%、フラボノール14.66%**程度のRMSE低下。6遺伝子モデルはLOOで僅かに最良でも、このグループ除外では分岐3遺伝子に劣る。したがって**「遺伝子を増やせば常に外挿が良くなる」とは言えない**。

種間系統的非独立性・コード群の意味・原著の選抜と前処理・生物学的反復の真の独立性・次世代予測を未検証として残す。ここでの正則化係数や6候補モデルの**別データでの事前検証・調整は未実施**。59種を59個の独立進化イベントとして扱う信頼区間やp値は計算しない。

## なぜIochrominae 2019の「CHIが最良」と矛盾しないか

[ANTO v25](IOCHROMINAE_V25_ENDPOINT_SPECIFIC_FLORAL_CHEMISTRY.md)はLarter et al. (2019)の**刊行済みAIC**を再計算したもの（両色素量の最良報告PGLS候補＝CHI）。**本v26は別Petunieaeの原著処理済み種データに固定ridge予測を行い、未知種の色素量を当てる誤差を測ったもの**である。

比較の異なる点は、対象系統、モデルの候補集合、回帰手法、目標物質、前処理、推定対象（学習標本への適合と種単位の将来測定ではない外挿）の全て。したがって「v25のCHI機構が誤り」「v26の分岐遺伝子が唯一の因果遺伝子」とは判定できない。

今回のより一般的な示唆は、**必要な分子状態の表現は予測対象と観測系・交差検証の単位に依存する**ことである。これは[EGWE](https://github.com/zuizui0223/egwe)の状態予測十分性という研究軸と接続し得るが、EGWEの条件付き予測実験や[izu-core](https://github.com/zuizui0223/izu-core)の遺伝的到達可能性結果を今回の59種で再現したとは呼ばない。

## 新しい生物学的能力の実証には、まだ何が足りないか

- 2019年の白花morphと白花固定種の**同じ個体に結びつく**色素・発現原本は元Dryad RARが401/403のため未取得。
- Petunieae 2023の処理済みRNA/HPLC種平均では、同一種・同一遺伝系統の**現在の生化学的な量的性質**は比較できるが、正常な祖先的酵素セットや調節経路の**機能的な共同能力**は直接測定していない。
- 出現した／消えた過去の形質経路と、遺伝子の修復、新しい経路、遺伝子移入、可塑性は区別できない。
- 次世代の色素発現、遺伝的保持、祖先色の本当の再進化、送粉者・食害者の適応利得、充実種子はこの論文の処理済み表から得られない。
- PetunieaeとIochrominaeは異なるtribeでも同じナス科・関連研究群であり、比較が直ちに独立な自然再進化例を得たことにはならない。**真の系統単位での独立holdout、原著phylogenetic treeとの種名突合、原著の公開試料メタデータの再照合**を次の実証監査とする。

花器官を対象としたCirsiumの実標本・遺伝型・訪花行動・子孫と適応度の試験は引き続き [aza3](https://github.com/zuizui0223/aza3) が管理する。ANTOの計算は新しい採集・操作の許可ではない。
