# 消えた表現型は、祖先と同じ形に戻るのか？ — ANTO v11 生物学的証拠の横断監査

**監査日：2026年10月20日。** 公開原論文の実験・分子・系統推定と、`anto`/`aza3` の実測台帳を別々の証拠として照合。これは系統的メタ解析ではなく、**機構の異なる実例を選んだ仮説生成用台帳**。新たに集めた植物個体、自然集団の「再進化率」、実証済み普遍法則はない。

## 1. 中心質問を再定義する

**旧：** 表現型が消失した後も、進化的可能性は残るか？

**新：** 消失した表現型の何が残り、どの組合せが再活性化されると、祖先の表現型・別の表現型・生殖機能のどこまで回復するのか？

特に、次の4結果を区別する。

1. **色素経路の存在／発現**（花以外で利用されている場合もある）。
2. **花での再発現**（元と同じ遺伝子の修復か、別の調節因子の動員か）。
3. **回復先**（祖先的な色素組成か、異なる色素・色相か）。
4. **世代間保持と適応度**（一過性の再発現でも、系統史的な再獲得でも、必ずしもその後の繁殖利得を意味しない）。

一つの論文・個体・系統の所見を別系統での独立再現として数えない。

## 3. 非自明な生態進化学的な構造

### 「機能の再起動」と「祖先表現型への復元」は一致しない

**2つの独立した属・系統の証拠がある：**
- Petuniaでは、祖先紫への経路修復と、別の調節因子による新しい赤への経路が**同じ属内**にある。
- Iochrominaeでは、祖先的デルフィニジンから無色化したA系統群内で、シアニジン主体の *I. edule* への再獲得が**系統上推定**され、花器官の後期経路発現も比較されている。

このことは「再び色が付けば元の色が戻ったはず」という**単純な二値状態推論に対する反例群**となる。ただしどれも既発表であり、2系統で同一の遺伝的機構が新しく再現されたという意味ではない。機構を識別した因果実験はPetunia中心で、I. eduleの復帰は系統比較に依存する。

### 遺伝子の存在とその機能は別、さらに花器官の機能は別

2016年Ho & Smithの22分類群の構造遺伝子は**flower-bud cDNA由来**である。この意味では、`anto` の以前の説明で「Iochrominaeには花組織のRNA証拠がない」と一括りにするのは誤り。花芽での転写産物が採取されていた。ただし**定量的な活性と酵素機能は未同定**で、別の2018年の研究は「初期経路が相対的に維持され、無色種では後期のDfr/Ans/F3′5′hが大きく低下」という結果を示した。

同様に琉球アザミは**若葉RNA**だけで、花器官の発現／代謝情報はゼロである。2系統を同じ「遺伝子保持」の階級に強引に入れない。

### 一般化に必要な推定対象

「いくつの再進化があったか」ではなく以下を独立に推定する：

- (P(再び色素を合成 mid 現在無色・同一系統の機能資源))
- (P(祖先色素経路まで再構築 mid 再発色))
- (P(世代を越えた再発現 mid まず発現))
- (E(生殖成功の変化 mid 回復先の色素状態・相互作用・環境))

現行の選抜6ケースからは、**これら4量を一つも頻度として推定できない**。1件（Petunia secreta）の祖先色相復帰と2件（Petunia exserta、I. edule）の異なる色相への再獲得候補は、標本頻度として1/3対2/3と報告してはいけない。

## 4. 次の実証で勝負する、予測の違い

**H1 経路資源の部分保存仮説：** 構造遺伝子の一部が残っていても、祖先の分岐色素まで戻す能力が残存するとは限らない。実際の生化学と酵素の基質特異性が必要。

**H2 調節子置換仮説：** 元の花色調節子が壊れていても、同じ下流経路を別の調節子が活性化できる。その場合、元と異なる色相や組織位置へ再発現が生じ得る。

**H3 生態的フィルター仮説：** 同じ見かけの再発色でも、送粉者・拮抗者・温度・UVなどの環境下での利益は別であり、再発現が3世代観測されることと実際に有利で維持されることは異なる。

**対立する帰無・代替経路：** 祖先色の単純保持、外部からの色素系統移入、過去の系統樹極性誤り、色素以外の色因子、花齢／光条件の可塑性、偶然の遺伝子保持。

H1/H2は既存原研究の結果・機構の拡張仮説であり、ここから特定の普遍的回復率・退化寿命を主張しない。

## 5. AZA3へ戻す測定順位

既存Phase-A 298個体計画を変えず、試料の来歴と許可が確保された場合だけ、以下の順で識別力を高める。

1. 同一個体の花弁（小花）における**発現した色素の種類**をLC-MS/HPLCで測定：単純な白／紫ラベルでは不十分。
2. 花と非花器官で、DFR/ANR、ANS/FLSの**実酵素ファミリーと産物**を分離。2020年候補TR39766/41106の2026年短断片だけでは機能不明。
3. 祖先花色・核遺伝子移入・倍数性を含む系統史と、花器官の調節子MYB–bHLH–WD40の組合せを検証。
4. 再発現が見えたときは遺伝的伝達・次世代同条件での再発現・生存痩果を別に測る。
5. カエル・ペンギン等の他プロジェクトから同じ「状態」という表現だけを借りて生態学的複製として数えない。

ここで必要な真の外部検証は、**アザミ以外の複数独立植物クレードで、発現能力と祖先色への回復を同じ測定粒度で観察すること**。野生近縁個体群が少ない場合も、未観測値にFALSEを埋めない。

## 6. 投稿戦略の判定

Forni et al. (2026, *Biological Reviews*, [DOI](https://doi.org/10.1002/brv.70168))は、形質喪失後の経路残存、表現型復帰と新規性の関係をすでに整理している。**「再進化は可能／元の形に戻るとは限らない」という文献要約だけでは新規性が不足する。**

いま最も価値があるのは、生物学的に測定可能な個体／系統単位で「色を取り戻す能力」と「祖先色へ戻る能力」の**予測可能性が実際に違うか**を外部系統でテストすること。復帰率の普遍的係数がなくとも、どの機能・遺伝・生態条件で回復先が変わるかを特定できれば、生態進化学上の新しい知見となり得る。

当面の研究所有権は `anto` = 汎植物比較と潜在的到達可能性、`aza3` = アザミの分子・同一個体花器官・送粉者/拮抗者・種子実証。
