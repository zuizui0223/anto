2026-11-17。原著 Hopkins et al. (2014), Current Biology DOI https://doi.org/10.1016/j.cub.2014.07.027 。著者が公開した PhloxHopkins/PhloxSelection の2014年7月10日コミット 60ff508170f1be592bbc6fe7ed46ac6e5b459026 に依拠。独立した新たな原著フィールド試験・原著MCMC75,000回の完全再現ではない。

## 最も重要な進捗

**公開元のC++コードの本来のWorld・Deme・初期頻度・花粉分散・選択・交配・尤度部分を原形のままC++11でビルドし、元のseedSet.paramsの13値を用いて5トランセクトを最後まで収束させ、原著の尤度関数そのものを実行できた。** 全5トランセクトで元の calcTotLike() と、同じ原著の MakeLikelihood() を花色・母株別子孫に分けて独立に和算した結果が一致した。2回の原始forward実行は完全一致。記録された確率ベクトルの正規化誤差は最大 2.886579864025407e−15。

## 予測に実際に含まれるもの

- 原著の**16通りの二遺伝子座型**（各遺伝子座2アレルの二倍体）、花の表現型DB/DR/LB/LR、空間36デーム・5トランセクト。
- Original source : 選択→雄配偶子/花粉移動→交配→子孫の遺伝子型分布と母株表現型に条件づけた子孫色型の確率行列。
- seedSet.paramsの開始値：トランセクト境界 .279/.362/.612/.639/.362、同色選別 a=0、移入分散パラメータ m=.72、二選択領域のDB/DR/LR選択係数 .88/.91/.90 および3.7/6.3/5.5。**これらは原著の最終推定ではなく開始値**。
- 原著の成体色型を重みとして源プログラムが予測した色型比率、母株ファミリーの実測子数を重みとして計算した子孫4色型の予測比率も、全トランセクト別にJSON原票へ保存した。これを使えば原著予測と元の母子データの不一致を次に解析可能。

## 発見したソフトウェア上の再現性障壁と対応

1. 公開の元リポジトリには **nr3.h** と、MCMC専用の **Rseeds.txt** が付属しない。したがって元のmain.cppをそのままコンパイルして75,000回MCMCを実行したという主張は**不可**。C++11の VecDoub / VecDoub_I / Doub と、旧コードの無修飾 cerr を解決する using std::cerr だけを書いた小さな**別の一時互換ヘッダー**を使用した。元World.cpp、Deme.cpp、initialfreq.cpp、simulate.cpp、WorldOutput.cpp、Params.cpp、utilities.cpp、likelihood.cppは変更しなかった。
2. 著者の原ファイル **inPhlox_Fam_T4.data** 末尾に、値の入っていないタブ/空白だけの**299行**がある。元のreaderは空行をそのまま母株として扱い得るため、Git SHAで認証後、一時的なワークディレクトリのコピーで**完全空行だけ**を削除。ヘッダーと非空行371件は元のバイトのまま維持。これは入力ソースの互換前処理であり、元ファイル自体のバイト完全一致とは呼ばない。
3. 元の著者のC++をUbuntu GCC 15.2でコンパイルすると、Params.cppの無修飾 cerr が最初に失敗した。このため上の互換ヘッダーに using std::cerr を加えた。**原著の生物学的パラメータ、観測値、尤度関数を変更したわけではない**。コンパイルは警告なしで成功した。
4. source Git commit SHA、v42の20 original Git blob SHA、v42の結果JSONとの完全一致を新規プログラムで強制。**全5トランセクトについて2回同じ結果が出ること**と元の尤度/二要素の和が一致することを検証した。

## 生態学的解釈とまだ解決していない重要なこと

- これで、Phloxの2遺伝子座の選択、花粉移動、交配が**元著者のモデル内でどのように親子の色型頻度を予測するか**を直接計算する実行基盤ができた。出力値は「環境ごとの選択が元コードで再現可能な機構を構成している」ことの動作上の裏づけであって、**その選択値を新しく野外から推定したわけではない**。
- v41/v42で判明した本論文の**12,024成体・382母株・2,581子孫**と著者の**11,379・371・2,496**（*example input*）の不一致**645/11/85**は未解決。今回のC++も後者の例示入力を使用した。
- 「子孫の色型」と「父方の遺伝子型」は別であり、親子の色型分離だけで適応的な花粉移動・遺伝子型ごとの選択効果は識別できない。
- 75,000回MCMC、原著の最尤点や事後信頼区間の再現、原著論文の全標本を対象とする完全モデル再計算はまだ実施していない。C++の開始値での単一尤度を高いフィットネスの証拠と呼ばない。
