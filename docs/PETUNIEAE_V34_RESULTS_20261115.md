## 結論

**真正クレードを丸ごと除外する条件では、同じ対象種・同じ訓練種数・最近縁訓練種までの同じ距離を保ちながら、他の訓練種の組合せだけを変えることができない。** 原著59種すべて、上限8種と15種の合計118対象条件で、枝長±1e−5単位の一致では許容される訓練集合が元の集合ただ1個だった。検証したのは数学的な代替集合の存在であり、分子情報の予測改善・生物学的因果効果ではない。

## なぜ厳密距離一致ができないか

除外クレードの構成種数を m とすると、訓練種数は 59−m になる。対象種 i より近い「クレード内の他の種」m−1種が存在する場合、最近縁訓練種までの距離を維持するにはその全員を除外しなければならない。除外予算も対象種を除けば m−1種分しかない。従って、除外する種の自由度が残らない。今回の原著のほぼ超距離的な dated tree では、この構造が厳密許容幅の全118対象条件で成立した。

実装では各 i に対して距離の下限より近い種を強制除外、許容範囲内の境界種を最低1種含める条件を課す。そのもとで、訓練種の代替集合数を

```
N_valid = choose(n_boundary + n_farther, n_train)
          - choose(n_farther, n_train)
N_nonidentical = N_valid - 1
```

と整数演算で求めた。N_valid=1は**元の1集合だけ**という意味であり、もう1つの独立した対照にはならない。N_valid=0なら構造やソースに矛盾があるため解析を止める。

## v33への帰結

- v33の「同じ種数のランダム除外」より真正クレード除外で分子情報の追加予測価値が高かった結果は**変わらない**。そのv33の比較は正当な *count-matched* 対照である。
- しかし「同じ最近縁距離まで保持して訓練種の構成だけを交換できる」という厳密な反事実は**存在しない**。従ってv33の差を *距離だけの因果効果* と *構成だけの因果効果* に分解したとは言えない。
- ±10～20%などの条件を緩めれば一部で数学的な代替集合は存在するが、**距離そのものも範囲内で変わる**。その後に予測をフィットしても完全な距離統制とは呼べない。
- 「近縁群の情報喪失に伴い分子情報がより役立つ可能性」をこの1原著のモデル内で主張する範囲は維持しつつ、距離・遺伝子発現・元の色素量・データ構成の交絡が残ると明記する。再進化、祖先機能保持、送粉者の選択、遺伝性、子孫適応度は測定していない。
