# ANTO v24 — 原著6種の白花／黄花多型は、自然での出現頻度より発生比較実験でどの程度多く採られたか

**2026年10月28日。新しい成果は原著で公開された実データTable 1の透明な再集計と、サンプリング設計の解析。原データDryad RARの花器官RNA/HPLCを新たに再解析したものではない。**

## 重要な区別：原著の頻度調査と機構比較の標本は別物

Larter, Dunbar-Wallis, Berardi & Smith (2019), *Developmental Dynamics* DOI [10.1002/dvdy.82](https://doi.org/10.1002/dvdy.82) の公開本文 **p.1094 Table 1** には、6つの花色多型種における**淡色（アントシアニン欠失）morphの推定出現頻度・調べた個体数**と、花器官の発生機構比較に**意図的に採った濃色／淡色の個体数**が明記されている。

2019年のDryad [doi:10.5061/dryad.p5dq84v](https://datadryad.org/dataset/doi:10.5061/dryad.p5dq84v) の真正RARは、先行[v23監査](IOCHROMA_2019_SOURCE_ACCESS_V23.md)でHTTP401/403のため取得できない。一方、[NSF公開元論文全文](https://par.nsf.gov/servlets/purl/10431252)のTable 1自体は読める。そこで**元論文の印刷表の各セル**をそのまま転記し、元ソースと分母が確認できる範囲の計算だけを行った。図から遺伝子発現や色素を目測抽出したのではない。

原著での「白」は、**白色だけでなく黄色のアントシアニン欠失morphも含む便宜的呼称**である。*Iochroma parvifolium* は明確に「紫／**黄色**」であり、文字どおりの白花ではない。

*「原著の調査対象数」は野外集団の観察と標本庫記録を含む。完全な無作為野外個体サンプルではなく、推定頻度の数値も丸められている。したがって、各種の **個々の真の白花数や二項分布の信頼区間を復元していない**。研究者が比較のために意図的に採った30個体も、自然の頻度を測るための無作為標本ではない。原著の実験設計自体を不適切と断定するものではない。

## 新しい元資料再集計結果：希少morphの意図的な高い採用割合

最初の4種では、報告された淡色morphの推定頻度は **0.9–1.8%**。この4種の各「調査対象数」で重み付けした*印刷済み推定頻度*の平均は

\[
\tilde p=\frac{\sum_{i=1}^4 n_i\hat p_i}{\sum_{i=1}^4n_i}
=\frac{9}{675}=\frac1{75}\simeq1.33\%.
\]

これは*推定頻度*と*異質な調査対象数*からの算術的記述である。原調査の白花の生の整数カウントや真の自然集団平均頻度の再推定ではない。

一方、**発生比較用の標本**では淡色morphを7個体、濃色morphを12個体採った。淡色は \(7/19\simeq36.84\%\)。したがって、

\[
\boxed{\text{比較用標本での淡色割合}\;/\;
\text{原著報告の調査数重み付き推定頻度}
= \frac{7/19}{1/75}=\frac{525}{19}\simeq27.63.}
\]

**この27.63倍は生態学的な相対危険、適応度効果、遺伝子発現の効果量、真の選択係数ではない。** 複数の機構を比較するため、希少な淡色morphを意図的に確保したという*標本構成*の差を定量化しただけである。このような採り方は原著の「種内白morphと色付き同種を比較する」目標に適切であり得るが、その比率を自然界での白花発生率に外挿できない。

最初の4種の各割合の比は概算 **27.78×、27.78×、30.77×、19.23×**。残りの2種（原著淡色頻度33%と57%）は約 **1.21×、0.88×**。この差は、白花が稀であるか一般的かによって、比較用標本の選択構造が大きく違うことを示す。

原著パーセントの印刷小数1桁を±0.05パーセントポイントに動かす*丸め誤差だけ*の感度計算では、希少4種の比はおおむね **26.63–28.71×** に残る。ただし**これは統計的区間や標本偏りの不確実性を含む信頼区間ではない**。

## 生物学的な独立反復が少ない点

2019年Table 1の6多型種のうち、*Iochroma calycinum* と *I. parvifolium* では淡色morphが**それぞれ1個体**のみ。原著自身も、これらの種内発現差の不確実性は淡色標本から推定できないと議論した。

希少4種を本当にp≈1%の**独立な無作為抽出**で4–6植物だけ測るという*現実の原著とは異なる仮想設計*なら、少なくとも1淡色個体を含む確率 \(1-(1-p)^n\) は約3.55–10.33%にとどまる。この計算は標本研究の理由を説明する反例であり、野外と標本庫の混合した元調査で二項無作為試行が成立していたと主張しない。

**ANTO v22への直接の教訓：** 1種につき淡色の1個体を採れたことは、その種の全個体が同じ「潜在的な機能資源」の状態である証拠にはならない。同一個体のqPCR技術反復数を増やしても、自然集団で多型頻度や真正の経路機能が均一であると実証したことにはならない。

## 2016年のGenBank配列データとの照合は5/6種に限る

ANTOがv19で凍結したHo & Smith (2016) の元の22分類群の配列登録と、原著2019年の6多型種を**元の分類群名**で照合した。5種は2016年登録リストにもあるが、**残りの *Saracha punctata* は登録された2016年22種に存在しない**。*Saracha quitensis* や *Saracha nigribaccata* に置き換えるのは偽の生物学的照合になる。

また、種名が一致した5種についても、2016年の**登録配列**は2019年の比較に採った**同一植物の共同機能検査**ではない。CDS注釈の有無は酵素活性の実測でもないため、2論文を結合して「同じ白花で祖先遺伝子の機能保存が証明された」とは言えない。

## 一般理論への接続：何を予測するのか

**異なる推定対象を区別する。**

- **種内の条件付き発生比較：** 白花を目的に採取した個体における遺伝子発現や色素濃度の比較。これは原著の研究目的であり、標本の白花頻度を自然頻度として解釈する必要はない。ただし遺伝的・環境的交絡と個体数には留意する。
- **自然集団での淡色頻度：** 独立に定義した集団と網羅的な抽出計画を必要とし、実験への意図的な白花登録比率で代用できない。
- **生物学的な潜在能力の保持率：** 同じ花器官・発達段階の共同機能測定、誤差校正、独立な植物個体を必要とする。2019年の報告済み淡色頻度も2016年の遺伝子登録も代用できない。
- **祖先型の真正な再進化と世代間維持：** 系統と遺伝子移入、複数独立遺伝系統における再発現・子孫適応度の追跡を別々に必要とする。

これらを混同すると、花色選択によって実験標本への登録確率が変わるだけで、自然での「隠れた再発現能力」が多い・少ないかを誤って判断するリスクがある。
