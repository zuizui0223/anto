## Key discoveries BEFORE new v42 source-code audit
- All 32 rows and 4 phenotype columns from ANTO v41 provisional Supplement Table S1 transcriptions matched the original author PhloxSelection phenotype files row-by-row, not merely total counts. Source code input has adult total 11,379, original manuscript text reports 12,024 (gap 645). This is not evidence that prior hand transcription was inaccurate. It establishes source-input-versus-article denominator mismatch requiring original authors' sample inclusion semantics. Do not impute 645 missing observations.
- Author example family input files have 371 nonempty original maternal family records and total 2,496 children (each source row is an original mother family, NOT an individual child and no original maternal accession IDs are present in those source files). Main article says 382 mothers and 2,581 offspring (gaps 11 mothers and 85 children). Mother's source phenotype is coded 0=DB, 1=DR, 2=LB, 3=LR (read source WorldOutput.cpp phenotype index). These are author EXAMPLE inputs, not guaranteed final Table S2 rows.
- Mother sample occurs in 30 of the 32 adult populations. Author input families for population IDs 330 and 332 are absent. This alone does not prove those populations are missing in original full Table S2, nor that they account for 11/85 missing aggregate counts.
- The author code's initial genotype-frequency files init_Phlox_IF1..5.txt are exact copies of the five phenotype count files by Git blob identity (no independent survey replicate). Do not count both.
