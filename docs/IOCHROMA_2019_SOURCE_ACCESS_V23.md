# ANTO v23 — 白花morphと固定白花種：2019年原データ入手監査

**2026-10-28。Dryad原データのメタデータは照合成功したが、真正のRARバイト列は未取得。独立した白花比較の新しい解析結果はない。**

## 研究の中心と原著への帰属

Larter, Dunbar-Wallis, Berardi & Smith (2019), *Developmental Dynamics*, DOI [10.1002/dvdy.82](https://doi.org/10.1002/dvdy.82) は、Iochrominaeで**有色種内にある白花morph**と、**種レベルで固定した白花種**を比較した。両者は花のアントシアニンの欠失が似ていても、固定白花種での後期色素経路遺伝子の低発現と、種内白花morphの有色個体に近い発現様式は異なる、という生物学的所見を発表している。

これは**原著者の既知の発見**であり、今回のANTOの新しい分子実験でも独立再解析結果でもない。2025年WheelerらのIochroma青花12・赤花12の交雑後代RNAと混ぜない。青／赤の24個体は2019年の白morph／白固定種を表現していない。

## 元個体別データが確認できた場合の解析契約（未実施）

1. 元RAR内部の個体ID、種名、種内morph、花器官、採取時期、field/greenhouse、HPLC・qPCRのリンクを復元する。独立な個体、技術反復、種、独立進化事象を混同しない。
2. **種内の白花morph対同種の有色morph**と、**固定白花種対別の有色種**を異なる比較単位で計算する。前者は種内ペア、後者は系統非独立性が必要。繰返し測定を独立クレードに見立てない。
3. 原著の前期CHS/CHI/F3Hと後期DFR/ANSの花での発現を、元著者が用いた参照・正規化尺度の下で検証する。別のRNA分母を無理に混ぜない。応答はHPLCの実測アントシアニン・フラボノール濃度と分離して扱う。
4. 予測を新たに評価できる場合のみ、全個体ランダム分割ではなく種を丸ごと保持した検証を用いる。ただし一つの近縁クレード内の検証は汎植物マクロ生態学の外部複製と呼ばない。
5. 試料不足・遺伝子未測定・植物と花齢の不一致・原データの変数不明があれば該当検定を実施しない。データがない変数の値を原論文図から勝手に作らない。

**測定できない結論：** 発現量の違いそのものから完全な酵素機能、祖先遺伝子の修復、遺伝子移入の排除、歴史的再進化、子孫への遺伝的保持、実際の適応度は確定できない。これらはv20–v22の機能測定と遺伝的・人口学的検証に別々に接続する。

## 研究判断

v23は**本当に実証すべき白morph／固定白花の対照を正しく守ったデータ取得ゲート**であり、2019年の原論文を新発見と見なすものではない。将来の原バイトアクセスが復旧するか、許諾された同一原本が得られた場合に限り、元個体単位で再解析を開始する。

同じく、琉球Cirsiumの真の花器官・送粉者・遺伝子・種子についての実測所有者は引き続き [aza3](https://github.com/zuizui0223/aza3) である。
