# ANTO v41 — 野外32集団と子孫2581個体に基づく2遺伝子座選択の地域差

2026-11-17。Hopkins et al. 2014 Current Biology 原著 Table1/Fig3とSupplement Table S1の数値を監査。今回新たな実験・元MCMC再実行は行っていない。

## 重要な知見（原著の公開モデル推定）

Hopkins, Guerrero, Rausher & Kirkpatrick (2014), DOI 10.1016/j.cub.2014.07.027 は5空間トランセクト・32自然集団で花色12,024個体と論文本体に記載し、382母株からの2,581子孫の花色も使って、花色遺伝子の局所選択と花粉移動を同時に推定した。各トランセクトは36デーム、報告クライン幅は淡色4km・赤色3.7km、花粉分散カーネルの分散はSupplementによれば0.83km²。これらは**原著著者の観測・推定**であり、v41独自のモデル最尤推定ではない。

| 原著の花色型と遺伝的背景 | 異所的地域・相対適応度 | P. cuspidata共存域・相対適応度 |
| --- | ---: | ---: |
| 淡青（LB：iiH_） | **1.00** | **0.17** |
| 濃青（DB：I_H_） | 0.86 | 0.53 |
| 淡赤（LR：iihh） | 0.89 | 0.86 |
| 濃赤（DR：I_hh） | 0.90 | **1.00** |

各地域で最良の花色型を別々に1.0とした元モデルの相対指標。野外の同じ植物個体から直接測った種子数比でも、自然次世代におけるアレル増加率でもない。地域内濃赤/淡青の相対比は異所的0.90、共存域約5.882。これらは独立に標準化された同一原著の別環境のモデル推定を比較しただけで、真の総適応度変化の因果推定ではない。

## 同じ2つの花色座の組合せ効果が環境で逆向きになる

原著Table1の表現型相対適応度から、著者が定義したエピスタシスを独立算術で復元した。

- 異所的地域：e = 1 − W_DB + W_DR − W_LR = 1 − 0.86 + 0.90 − 0.89 = **+0.15**。原著95%区間[0.11, 0.19]。
- 共存域：e = 1 − W_DB + W_LB − W_LR = 1 − 0.53 + 0.17 − 0.86 = **−0.22**。原著95%区間[−0.37, 0]。
- 生態学的含意：花弁色素量と色相を決める2座の間の**適応度上の非加算性**が地域で変わる。色素濃さを増すという同じ制御変異でも、遺伝的背景と地域の送粉・交雑環境が結果を変え得る。
- 原著の選択係数も、異所的で濃さの派生アレルIは**s_I = −0.14**（区間−0.17〜−0.10）、共存域では逆に祖先型の淡色アレルiが**s_i = −0.47**（−0.69〜−0.30）と不利。色相についても異所的な赤hは−0.11、共存域で祖先の青Hは−0.14。ただしこれらは**著者が空間モデルから推定した別基準の遺伝子座選択係数**で、v40の2012年の単純な生存可能雑種を基準にしたs=+0.323とは同一推定量ではない。
- 2012年の単独野外実験で色相遺伝子座の異種交雑効果が有意でなかったのに対し、2014年の広域空間モデルで色相座にも選択が推定された。これを同じ試験の矛盾とみなさず、測定範囲・時間・モデル仮定が異なると扱う。

出典：[2014年本体原著](https://doi.org/10.1016/j.cub.2014.07.027)、[著者公開PDF](https://people.duke.edu/~mrausher/Hopkins%20et%20al.%202014.pdf)。

## ANTO × EGWE × izu-core / 次の直接の実証

- v41原著から実証できるのは、**異なる花色形質の適応度推定が地理的に逆転し、色素の濃さ×色相の遺伝子座エピスタシスも逆符号となること**。これにより「ある状態への可到達性」と「ある地域での維持」の違いが具体化する。
- ただし、花色の喪失後に祖先色が復元された履歴（P. secreta/AN2）の成功確率を、このP. drummondiiの12k個体で測ったわけではない。天然集団で多数世代のアレルを追ったわけでもない。地域ごとの花色推定適応度は、複数の繁殖機構が混ざり、2014年のモデル自身は直接の選択原因を識別していない。
- 次に最優先するのはSupplementの原著画像による32集団値の独立照合と、Table S2の382母株×2,581子の原著表の行レベル取得。これで原著モデルへの近似計算、トランセクトごとの配偶体混合検証、再現検査へ進める。元の著者MCMCを忠実に再構築するには遺伝形式・花粉分散・境界・同一デーム数などすべての仕様が必要。source mismatchを解決するまで『完全再現』は申告しない。
