# Iochroma 花色別RNA相関の個体除外・尺度感度監査 v3

**2026-10-26｜公開元の同一24個体に対する追加記述解析。独立した植物集団での検証、遺伝子機能実験、進化史の復元、適応度の実測ではない。**

## 問い

[先行v2解析](IOCHROMA_2025_PHENOTYPE_CONDITIONED_COEXPRESSION_V2.md)では、著者が候補としたMYB12-like転写産物に対し、同じ原著24個体（青花12、赤花12）で青赤を完全分離する他の15転写産物は**混合データでは15/15正のPearson相関**だった。しかし花色群ごとの平均をそれぞれ除去すると、**9/15が負**になった。

今回、これら9件が少数の個体や測定尺度に左右されているかを、**解析定義を先に固定**して調べた。

## 全24個体の1個体除外結果

各反復では、青または赤の**元の生物学的1個体だけを除外**し、残り23個体について各転写産物の花色群平均を**改めて計算**し、残差のPearson相関を評価した。元の群平均を使い回す方法ではない。

| 元の花色平均調整後に負だった9件 | 結果 |
|---|---:|
| **24回すべての除外で負を維持** | **4/9** |
| **少なくとも1回の除外で正へ反転** | **5/9** |
| **log(1+TPM)へ変換後も負** | **6/9** |
| **24回すべての除外とlog変換の両方で負** | **4/9** |

両方の規準を満たした元転写産物IDは `TRINITY_DN1372_c0_g1_i30.p1`, `TRINITY_DN5810_c0_g1_i18.p1`, `TRINITY_DN6574_c0_g1_i12.p1`, `TRINITY_DN6994_c1_g1_i1.p1` の4件。これらも**因果的な抑制遺伝子や祖先機能資源の保存を検証したことにはならない**。

残り5件のうち数件は一個体を除くと符号が変わり、3件はlog1p変換で負から正へ変わった。全9件を同じ「負の共発現」という確実性で数えない。

## 花色群別の相関とは別の推定量

v2・v3の**花色平均調整後のPearson相関**は、青群・赤群それぞれの平均を引いた残差を、**全24個体で一緒に相関**させるもの。青群と赤群のそれぞれで負であるという主張ではない。

そのため今回は**別途**、青群12個体だけの相関と赤群12個体だけの相関も算出した。赤群では発現が全員0などの一定ベクトルがあるため、**5/15の比較で赤群だけのPearson相関は未定義**だった。未定義をゼロ・陰性・無相関として補完していない。

## ANTO v9–v18への接続と限界

**支持される観察結果：** 同じ花色群を完全に識別する15転写産物は、MYB12-like候補と全体で正に相関しても、花色群内の共変化まで一様に正とは限らない。さらに負の残差相関の一部は、特定個体・TPM尺度への依存が強い。

**未実証：** 遺伝子間の直接抑制、花色素経路の同一個体での完全な機能、祖先遺伝子の再活性化、白花固定系統のRNAとの比較、複数系統での繰り返し、環境自己相関による潜在能力の保存、子孫への遺伝伝達、充実種子や長期の適応度。

このデータは**赤花・青花の1交配後代の花器官RNA**であり、2019年の同属・近縁系統の白花morphと固定白花種の公開データを新しく再解析したものでもない。v17/v18のマルコフ環境・分枝過程の自然パラメータはここから校正できない。Cirsiumの分子・花器官・種子に関する実証実装は引き続き[aza3](https://github.com/zuizui0223/aza3)が担当する。
