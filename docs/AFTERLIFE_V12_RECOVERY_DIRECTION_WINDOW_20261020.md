# ANTO v12 — 回復能力が減る一方、最初の回復先が別型へ移る条件

2026-10-20. **今回新しく計算した、明示的な仮定の下でのモデル結果。植物で新たに測定した率ではない。**
基点: `anto@3efa90dbd5f95469ff4f8732606e8c8d64b0a347`（v11）。v10/v10bの再発現・継続性モデル、v11の原著比較、全Cirsium実証を所有するaza3は変更しない。

## 1. 結果と問い

前段の「色が再び付くことと祖先色に戻ることは異なる」という比較から、**回復全体のしやすさと、最初にどの表現型へ回復するかが反対方向に動く条件**を検証した。

仮定した同じ環境・同じ再発現率の下で、未発現期間が長くなると総回復確率は下がる。しかし祖先型の経路だけが早く失われる場合、**別型が最初に現れる絶対確率は中間の期間で高くなり得る**。別型を作る分子機能が改善されたからではなく、先に祖先型へ到達する経路が減るためである。

重要な対照: 祖先型が先に現れても、その後の別型の発現をすべて数えるなら、この増加は消える。したがって主張は**最初の回復先の分布**についてであり、「喪失がイノベーション能力を高める」という一般則ではない。

## 2. モデル・生物学的意味・計測対象

必要資源を3ブロックに分ける。Cは共有の発現基盤、Aは祖先型への経路固有の資源、Bは別型への経路固有の資源。C+Aが祖先型、C+Bが別型を発現可能にする。これらは特定遺伝子名やホモログの有無ではなく、**機能的に定義した必要資源**である。

最初は全資源があり、表現型は未発現。環境が再発現を許すまでの期間tには発現事象を許さず、資源は独立な指数待ち時間で不可逆的に失われる。その後、必要資源がある間、祖先型は率a、別型は率bで発現する。共有・祖先・別型の資源喪失率はc,x,yとする。主例は機会復帰前後で同じ喪失率を使うが、コードは前後別の喪失率も許す。

記録するのは、(i) 祖先型が最初に出る、(ii) 別型が最初に出る、(iii) 観察期間中にどちらも出ない、の確率。最初の事象ラベルを吸収状態として記録するが、**生物が永久に固定される、後の型変更が不可能になる、という仮定ではない**。

資源喪失後の修復・新規変異・遺伝子移入・組換え・種子銀行・集団絶滅・繁殖成功はこのモデルに入れていない。時刻は任意のモデル時間であり、実測された年数や世代数ではない。A/Bの発現率は適応度や固定確率と同一視しない。

各ブロックが複数の独立で必要な部品から成る場合は、部品の喪失率を足し合わせて同じ式を使える。ただし、部品間依存、代替補償、可逆修復がある場合はこの縮約を再検証する必要がある。

## 3. 解析解

全資源が存在する時点から追跡し、L=a+b+c+x+yと置く。片側だけ残る場合の回復確率は

\[
u_A=\frac{a}{a+c+x},\qquad u_B=\frac{b}{b+c+y}.
\]

全資源からの最初の回復確率は、最初の遷移による分解から

\[
p_A=\frac{a+y u_A}{L},\qquad p_B=\frac{b+x u_B}{L}.
\]

祖先型の率aは変えず、その固有資源の喪失率xだけを変えると

\[
\frac{\partial p_B}{\partial x}
 =\frac{ab}{(b+c+y)L^2}>0\quad(a,b>0).
\]

一方、総回復確率p_A+p_Bは減少または不変になる。これは同じ潜在事象時刻を共有する結合で理解できる: Aの機能寿命を短くしてもBの発現時刻は早くならず、いずれかの成功機会を新しく追加することもない。変わるのは、Bより先にAが現れていた一部の軌跡である。

### 無発現期間に対する中間ピーク

機会が戻る前の喪失率をc0,x0,y0、k=c0+y0、u=u_B、v=u_B-p_Bと置く。最初の別型回復確率は

\[
B(t)=e^{-kt}\{u-v e^{-x_0t}\}.
\]

k,x0>0のとき、内部の最大値を持つ必要十分条件は

\[
x_0v>k(u-v)=k p_B.
\]

成立時は

\[
t^*=\frac{1}{x_0}\log\frac{(k+x_0)v}{k u}.
\]

つまり、**祖先経路が失われて先行回復が減る効果が、共通基盤・別型経路そのものを失う効果より強い場合**にのみ、中間ピークが生じる。両側が対称な主対照ではピークは生じない。共有基盤と別型経路が永久に保存される極限は有限ピークではなく漸近的増加になる。

これは既知の指数過程・競合リスクの数学を組み合わせた、本プログラム内の条件付き結果。新しい一般確率定理とは位置づけない。

## 4. 実際に計算した例

a=0.40、b=0.20、c=0.02、x=0.30、y=0.01。初期の機能資源も再発現可能になった後の環境も同じで、無発現の待機期間だけを変更。

| 機会復帰までの期間t（モデル時間） | 祖先型が最初 | 別型が最初 | 何らかの最初の回復 |
|---:|---:|---:|---:|
| 0 | 43.608% | 49.556% | 93.164% |
| 5 | 8.922% | 67.661% | 76.583% |
| 20 | 0.076% | 47.672% | 47.748% |

最初の別型回復のピークはt=5.180584、確率67.6725%。その時点の全回復確率は76.0975%で、即座に機会が戻る場合の93.1640%より低い。長く待つほど常によいわけではなく、さらに待てば別型の回復も減る。

この表は機会復帰後の無限追跡で計算した。**10モデル時間の有限追跡でも**、t=0→t=5.180584で、別型が最初になる確率は45.8184%→61.1105%に増え、全回復は89.4208%→69.5340%に低下した。無限時間のみに由来する結果ではない。

### 先行イベントを打ち切らない対照

Aが先に発現してもBをその後も追い続け、Aの発現がC/Bの機能や寿命を変えない場合:

\[
P(B\text{がいつか発現})=e^{-kt}\frac{b}{b+c+y}.
\]

これはtに対して単調に減少する。上の同じ例では86.9565%→74.8442%→47.7228%（t=0,5,20）。**別型への固有能力が増したという解釈は、この対照で否定される。**最初に観察される回復先と、後に到達できる型を含めた全能力の区別が必要になる。

- 競合リスクにおける事象固有の率と累積発生確率の区別は既存手法: Andersen et al. 2012, https://doi.org/10.1093/ije/dyr213

今回の独自作業は、これらの植物事例を再発見したことではなく、**総回復能力と最初の回復先が異なる動きをする条件、対照下では消える条件を、実行可能なモデルとして計算したこと**。

実証で検証すべき予測は「古い無色系統ほどイノベーションする」ではない。機能的に共有基盤・祖先型固有経路・別型経路を別々に測り、同条件の再発現を追跡したとき、祖先型固有経路の低下が**全回復の低下と初発経路の偏りの両方**を説明するか、である。祖先型出現後の追跡も行い、先行事象による分類効果と、別型の実能力増大を分離する。

Cirsium実験はaza3で行い、若葉ホモログ断片を機能的C/A/Bへ置き換えない。ここでは試料数・採集計画・生殖実験を変更せず、自然界の回復寿命、繁殖利益、固定確率を推定していない。現行v11の文献台帳とv10の継続性評価を、この解析で上書きしない。
