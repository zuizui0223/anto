# ANTO v40：花色アレルの利益は送粉者・異種交雑・雑種不稔・競合的コストで変化する

**2026年11月16日：Hopkins & Rausher 2012原著の公刊パラメータを厳密再計算し、2014年の別の異所的原著の送粉者選好と区別して接続した。生物実験の新規実施ではない。**

## 中核：原著2012年の選択係数を、条件付きの利益に分解

Hopkins & Rausher (2012) *Science* [DOI 10.1126/science.1215198](https://doi.org/10.1126/science.1215198)、[著者公開PDF](https://hopkins-lab.org/wp-content/uploads/2014/12/Hopkins-and-Rausher_2012.pdf) およびSupplementで用いられた集計：

- 近縁種 *P. cuspidata* が共存する条件で、淡青の参照花の異種交雑率 **h_L=0.43**、濃色花の異種交雑率 **h_D=0.21**。原著のFig.1Dでは**931種子の父性判定**を行い、4ブロックの参照交雑率の範囲は28〜44%。この931は**931件の独立した進化現象ではなく種子サンプル数**。
- 雑種の不稔率 **q=0.90** は他の原著に基づく当該研究の仮定であって、この父性サンプリングで新たに推定した値ではない。
- 原著モデルの生存可能子孫の比例指標 `W(h)=1−q h` より **W_L=0.613、W_D=0.811**、`s = W_D/W_L −1 = 0.32300163`。原著の丸めた選択係数 **s≈0.32** と完全一致。
- 色素**濃度（intensity）を増やすR2R3-MYB関連アレル**に対応する雑種減少は **51.16%**。対して**色相（赤・青）を変えるF3′5′H関連アレル**には、同様の異種交雑減少は検出されなかった。両遺伝子座へ同じsを代入してはいけない。
- 原著の送粉者移動試験（181送粉者、2,301植物間移動）は父性判定931種子の**同一個体または同一花の直接対応表ではない**。sを自然集団内の複数世代実測アレル頻度変化と扱わない。

## 元の交雑率を固定した6つの雑種不稔率シナリオ

| 想定する雑種不稔率 q | 推定的な濃色アレルの相対利益 s |
| ---: | ---: |
| 0% | **0.000** |
| 25% | +0.0616 |
| 50% | +0.1401 |
| 75% | +0.2435 |
| **90%（原著の仮定）** | **+0.3230** |
| 100% | +0.3860 |

ここでの6つのqは**実測された6地域や6実験ではない**。同じ2012年原著の交雑率を使い、不稔率だけを仮定で変えた数学的な感度分析である。

**新しい定量的境界条件：** 濃色アレルに「異種交雑を避ける利益と独立した別の繁殖上の不利益」`c` が乗算でかかると仮定すると、

```
W_light = 1 - q h_light
W_dark  = (1-c)(1-q h_dark)
s_net   = W_dark/W_light - 1
c_break_even = 1 - (1-q h_light)/(1-q h_dark)
```

原著の **q=.90** に固定した場合、**c_break_even = 0.2441430333（24.41%）**。例えば c=20%の仮定なら`s_net=+0.0584`、c=25%の仮定では`s_net=−0.00775`。この24.4%は**実測された色素生産コストではなく、単純なモデルの損益分岐点**である。

逆にコストを先に仮定した場合、濃色アレルが有利になるために必要な雑種不稔率は以下となる。

| 仮定上の濃色型の別コスト c | 必要な不稔率 q の境界 |
| ---: | ---: |
| 5% | 21.69% |
| 10% | 41.49% |
| 20% | 76.34% |
| 25% | 91.74% |
| 30% | **106.01%（生物学的に達成不能）** |

`q_threshold(c)=c/[h_light−(1−c)h_dark]` から厳密に算出した。これも**雑種不稔の新規標本推定や効果の信頼区間ではなく、原著のhが変わらないという反事実シナリオ**である。少なくとも「強い不稔率がないと濃色型の利益が減る」「別コストが大きければ同じ形質が不利になる」が数式で確認できる。

## 2014年の独立した原著：異所的集団では祖先型への訪花選好

Hopkins & Rausher (2014) *American Naturalist* [DOI 10.1086/675495](https://doi.org/10.1086/675495)、[著者公開本文PDF](https://hopkins-lab.org/wp-content/uploads/2015/03/HopkinsRausher_2014.pdf) は、**同じPhlox drummondii放散の別の自然生息環境**を使った研究。原著は2010・2011年の野外の生存・結実と、花色アレイでの278送粉者・1,000訪花を報告。原著Table4の3アレイの集計（nは各アレイに含まれる送粉者数で、総計278と完全一致する必要はない）：

| 淡青型と比較した花色 | アレイN | 淡青型が得た訪花比率 | 原著bootstrap 95%区間 |
| --- | ---: | ---: | --- |
| 淡赤 | 84 | **61.9%** | 57.1–66.6% |
| 濃青 | 118 | **60.3%** | 55.3–65.3% |
| 濃赤 | 74 | **68.2%** | 63.4–73.2% |

いずれも原著で淡青型への選好が報告されている。ただし、訪花データの公刊区間は原著のbootstrap推定であり、**送粉者内の反復訪花を独立と仮定した今回の新しい二項検定ではない**。2014年の原著は雄性の父性成果を直接測定しておらず、この訪花割合を2012年の「異種交雑率」や「W(h)」へ変換することもできない。

特に2014年原著は2010と2011年で気候条件が異なり、生存・果実生産・花粉成果の仮定で総合的な選択予測が変化した。**異所的な淡青花への訪花選好があっても、濃色/赤色アレルの純適応度が常に負になると実測されたわけではない**。その上限を超えて「地域ごとに明確に実測された選択係数の符号反転」と主張しない。

原著2014年のDryad DOI [10.5061/dryad.f710n](https://doi.org/10.5061/dryad.f710n) の個体別観測行を今回取得・再解析したわけではない。2012年の931種子父性記録も著者公刊の要約数値から計算しており、原行レベルで不確実性を再推定していない。

## ANTO × EGWE × izu-core 一般理論への接続

同じ花色形質は、**ある地域で近縁種との交雑を避ける機能**を果たし、**別の地域では祖先型を好む送粉者の利用とのトレードオフ**に置かれ得る。したがって、機能が遺伝的に再出現できたかだけでなく、その形質が*どの環境のどの繁殖段階で有利か*が将来の維持を左右する。

今回原著と独立計算で確かめた範囲：
1. **2012年の局所的な雑種交配コスト回避の利益**：原著の父性実測＋仮定の不稔率に基づくs=0.323。色素濃さのアレルで支持、赤色相のアレルではこの機構を支持する差が未検出。
2. **2014年の異所的訪花選好**：3アレイで淡青が選ばれることを原著測定。雄・雌適応度の総和は環境とモデル仮定に依存。
3. **v40の新しい数式による損益分岐**：原著の交雑率を固定した場合の不稔率感度と、仮定の別コスト24.4%の境界。**新しい観察生物データではない**。
4. **未解決**：同じ自然個体の配列機能→花色→訪花→交配相手→成功種子→子孫の遺伝子頻度を接続した多世代研究、地域別の真のコスト率、遺伝子型別の雄・雌適応度と移入率。

重要な仮説は「同じ再獲得能力の分子基盤でも、雑種不稔と送粉者選好の地域差、別のコストにより形質の選択方向は変わり得る」。今回の分析はその**条件付き予測と既存原著の支持する部分**を明確にした段階で、統合理論全体の因果実証や自然の再進化率の推定ではない。
