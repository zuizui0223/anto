# ANTO v32 — 系統予測に花芽RNA情報を加えたときの追加価値

**2026-11-14｜v31後の探索的再解析。新しい野外データ・独立した生物学的再現ではない。**

## 結論

**3遺伝子の追加が常に有利、という主判定は成立しなかった。** 59種の1種ずつの除外では、アントシアニジン総量のRMSEは0.96%改善したがMAEは悪化し、フラボノール総量のRMSEは3.29%改善した。一方、同じ59種でクレードをまとめて除外すると、同じ系統モデルに発現情報を加えることでRMSEが約9–16%改善した。

これは「遺伝子の情報価値は、予測対象と利用できる近縁種の構成に依存する」という限定的な予測上の結果であり、系統距離の因果効果、遺伝子の機能証明、祖先花色の再進化を意味しない。

## 比較方法

原著2023年の年代付き系統樹について、根から共通祖先までの共有枝長を共分散とするモデルを使用した。P＝系統のみの予測、P+G＝その同じモデルにF3primeH/F35H/FLSの発現情報を加えた予測。比較する両モデルで系統成分の設定は共通とし、0.01/0.1/1/10の候補から各外側訓練集合内の内側留一予測で選んだ。外側評価種の化学量は選択・標準化・係数推定に使わない。遺伝子係数のridge penaltyは従来の10に固定。Brownian型共分散は解析上の仮定で、実際の色素進化過程を検証したものではない。

## 全8比較の結果

RMSEはそれぞれの化学量のlog1p尺度。物質間の絶対値を効果量として比較しない。正の改善率はP+GがPより良い。

31種のフラボノールでは改善した種は13/31で、同じ除外感度集計でも−7.8070～−3.3840%と悪化が残った。31種は59種の部分集合であり、独立研究ではない。

## クレードを除いたときの肯定結果の強さと限界

最大8種の分割は14群で、P+Gの平均二乗誤差が小さかったのは両物質とも11/14群。最大15種の分割は6群で、両物質とも6/6群が改善した。両分割・両物質の全4ケースで、4つの固定共分散設定のいずれでもRMSE改善の方向は正だった。評価済みの1種の誤差を除いても改善は全4ケースで正のまま。これらは依存する感度解析であり、独立反復数や信頼区間には数えない。

ただし、最大15種のクレード除外ではP自体が訓練平均とほぼ同程度かそれより悪い。平均のRMSEはアントシアニジン0.42736142、フラボノール1.44264396。このため、クレード除外時の大きな追加利得を「すべての系統モデルより優れる」と解釈しない。

**系統と遺伝子を組み合わせれば常に最良、でもない。** 59種の1種除外では遺伝子だけのモデルのRMSEは0.32961162・1.18667618で、P+Gより両方とも低い。最大8種のクレード除外・アントシアニジンではP+Gが遺伝子のみ（0.33461242）も上回るが、この相乗的な改善は全条件共通ではない。

## 読み方

v31で最近縁種転用に対して得た22–27%の改善と、今回の追加効果は**比較対象が違う**。今回のPは系統樹全体の共有履歴と訓練種の化学量を用いて予測する。主解析のPは訓練平均より良く、v31の単純な最近縁種転用より強い基準になった。その強い基準に対して、追加価値が小さい場合・負になる場合・クレード外挿で大きくなる場合を区別できた。

考察に使えるのは、**利用可能な系統情報と現在の分子状態情報の価値が、予測の範囲によって変わる**という仮説である。どのクレード・遺伝子調節・色素代謝が原因か、あるいは遺伝的適応・可塑性・進化的再獲得なのかは、この原著の現在の種平均からは識別していない。独立RNA/HPLC研究や機能実験は別途必要。
