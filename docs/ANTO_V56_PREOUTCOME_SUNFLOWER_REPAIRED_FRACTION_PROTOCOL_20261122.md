Use equal weight among 3 or 4 matched distance bands to construct **ONE original field-year outcome** y, one x_reported and one x_reconstructed. Exact admission is **80 distinct field-years / 51 unique original physical fields**, all source metadata (region, habitat category, year and original physical name) matching between source tables, no missing original target bands, all original outcomes y∈[0,1]. If any further source inconsistency arises, FAIL CLOSED and report data quality rather than choosing favorable lower coverage. Use original **2,214 included harvest and all 11,682 visit records** in these bands.

Use the original v55 fixed model functions **without modification** for each of the 51 original physical-field-heldout folds: response original field-year seed-set fraction, original Z0 baseline intercept + Year2018, RegionCuenca and Field_Type SNV/WFS dummies, unpenalized intercept and all other slopes ridge lambda 8; original Z1 PRIMARY adds training-only standardized log1p(REPORTED total bee interactions per monitored flower-minute); original Z2 SECONDARY adds training-only standardized log1p(APIS+WILD reconstructed interactions per monitored flower-minute). ## Fixed source-label placebo and decision

Original v55 placebo is retained: 200 seed 20261119 source visitor-rate paired shuffles within original Region×Year×Field_Type; original field-year seed outcomes, season/site labels, physical-field folds and both reported/reconstructed visitation measures remain as originally recorded except paired predictor identity shuffles. Refitting only original Z1 with 51 same physical-field folds, calculate the signed equal-field Z0−Z1 gain distribution. It is a **descriptive label-association control**, not a valid causal randomized insect intervention or p value.

**Pre-v56-output descriptive support gate**: Z0−Z1 MSE reduction is >0 for both equal-field and field-year-weighted risk; >half of physical fields have a positive reduction; both region-specific field-year means and ≥2 of 3 habitat types have positive gain; observed equal-field gain > placebo q97.5. A failure is `VISITOR_INFORMATION_FIELD_TRANSFER_NOT_ESTABLISHED` even if some alternative guild-reconstructed model performs better. A pass yields `DESCRIPTIVE_SINGLE_ORIGINAL_CROP_STUDY_FIELD_TRANSFER`, not causal pollination, heritable fitness, a flower-trait evolutionary law or a second original Mota study.
